# 🍎 Aurora Server for macOS (Apple Silicon)

**Your media. Your server. Your world.**

> [!IMPORTANT]
> **Private development only.** Aurora Server for macOS is not currently offered as a public download. This page is a public status overview, **not** an installation, update, uninstall or recovery procedure.

## Current development status

Aurora Server has a working **Apple Silicon / ARM64** implementation in private testing. Its installation, service management, database, backup, update and recovery workflows are being validated before wider distribution.

Public compatibility guarantees, minimum macOS version, disk and memory requirements, and specific installer instructions have **not** been finalized. This page does not announce support for Intel Macs.

## What the macOS server is designed to provide

- A self-hosted Aurora Server environment
- Media-library indexing and management
- Account, configuration and metadata services
- Video and audio delivery to supported clients
- Integration with Aurora Desktop, Experience and supported devices

Supported behavior varies with the actual test build and hardware. Media formats and acceleration capabilities will be documented only after validation.

## Download and install availability

**There is no official public macOS installer here yet.** Do not rely on third-party download links, unofficial packages or example commands circulated outside authorized testing.

If you are invited to a private test, use only the instructions supplied with **that specific build**. Those instructions should identify how to install, verify, update, back up and recover the server safely.

## Existing private installations

Do not assume that an update is safe simply because a package installs successfully. Existing users should follow their build-specific backup, migration verification and recovery guidance.

**Do not run cleanup, uninstall or purge commands copied from old development guides.** Some operations can irreversibly remove databases, configuration and backups. Preserve independent backups of irreplaceable files before modifying an installation.
