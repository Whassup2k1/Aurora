# Aurora Roadmap

Aurora is evolving from a music-first application into a complete, self-hosted multimedia hub.

This roadmap reflects the current direction of the project. Priorities may evolve as the platform matures.

## Current foundation

Aurora already has a substantial native foundation:

- Aurora Server
- native music catalog and library scanning
- audio streaming and seeking
- albums, artists, playlists and favorites
- global search
- artwork and metadata management
- administration interface
- PostgreSQL-backed data layer
- API integrations
- backups and update infrastructure
- local HTTPS and network discovery
- Linux packaging
- guitar tabs and practice tools
- music news foundation

## Next milestone — 0.10.10

The next development milestone focuses on consolidating the 0.10.x foundation.

Priorities include:

- resolve the known M3U issue identified during 0.10.9 validation
- continue hardening Aurora Server
- improve installation and upgrade reliability
- continue consolidating Aurora's native media architecture
- polish repository structure and documentation
- expand automated and manual validation

## Music

Aurora will continue to deepen its music experience with:

- richer artist and album experiences
- improved discovery
- advanced queue and playlist tools
- metadata enrichment
- artwork management
- audio enhancements and equalization
- Master Reference mode
- improved multi-user personalization

## Karaoke

Planned work includes:

- synchronized lyrics
- fullscreen karaoke experience
- singer queue and rotation
- party-friendly controls
- deeper integration with the local music library

## Guitar Tabs & Practice

Aurora's practice environment is being expanded around AlphaTab with:

- Guitar Pro import
- tablature and standard notation
- track selection
- speed control
- metronome and count-in
- A/B looping
- tuning and transposition tools
- MIDI
- printing
- dedicated practice workflows

## Movies, Series & TV

Aurora is expanding into a unified video experience with:

- movies
- series
- live TV
- IPTV
- posters and backdrops
- metadata
- trailers
- watch progress
- unified search
- dedicated video dashboards

## Unified Home

Aurora's long-term home experience will combine multiple media worlds in one adaptive dashboard while preserving dedicated experiences for Music, Movies & Series, TV, News, Karaoke and Guitar.

## Aurora Server

The server roadmap includes:

- continued development of Aurora's fully native media stack
- universal installation
- safer upgrades and rollback
- backup and recovery
- diagnostics
- multi-user support
- secure integrations
- broader platform support

## Platforms

Current focus:

- Linux / Ubuntu Server
- web interface

Planned:

- Windows
- macOS
- additional Linux distributions
- TV clients
- Apple TV / TV experience
- additional client platforms

## Public release

Before Aurora's first stable public release, the project must reach a level where installation, upgrades, recovery, core media playback and administration can be trusted by users without requiring them to understand Aurora's internal infrastructure.

Aurora is under active development. This roadmap describes direction rather than guaranteed release dates.
