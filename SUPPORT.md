## Before submitting feedback

A useful report describes what you expected, what happened, the feature and device involved, and steps to reproduce. If you are an authorized tester, mention the client/platform and a build identifier only if provided.

Do **not** publish credentials, access tokens, API keys, internal addresses, private media filenames, personal data, unredacted logs or screenshots containing secrets.

## Current availability

Aurora Desktop, Experience, Android, Server and Cinema Engine are in different stages of private development and validation. A working internal capability does not imply public availability or support for a given device or codec.

Public installation instructions and supported hardware will be provided only when corresponding builds are ready. See [Installation](INSTALLATION.md).

## Languages and accessibility

The private project currently supports French and English; future languages remain unannounced. Reports about untranslated text, focus/navigation problems, legibility and accessibility are welcome.

## Community expectations

Be respectful, avoid posting copyrighted third-party content or confidential information, and distinguish personal workarounds from officially documented solutions. Aurora does not supply commercial media catalogs or IPTV subscriptions.
